# Harness 与评测设计复盘

在香港城市规划背景调查（Planning Research）场景中，直接让大语言模型通读多份官方 PDF 并输出“能不能做”的结论，通常会遇到三个实务问题：
1. **角色混淆**：把申请人陈述、委员讨论意见（例如曾讨论将食肆比例降为 30%）当成城规会最终批准条件；
2. **口径混用**：把申请方案的约数地积比（PR）当成法定规划上限，或忽视不同文件之间的边界与面积口径差异；
3. **静默编造与版本错位**：找不到现行图则或续期记录时自行脑补结论，或把旧版文件的页码引用套用到新文件上。

围绕这些痛点，本项目把模型能力限定在“候选提取”阶段，把校验、定位与初步倾向计算全部收拢进确定性 Harness 中。

---

## 1. 确定性代码与模型的职责切分

| 环节 | 交给谁 | 实现方式与源码依据 |
|---|---|---|
| 官方文件抓取与历史快照 | 确定性代码 | 按完整申请编号建夹，记录获取时间与内容哈希，按日期或运行批次隔离视图（[`app/research.py`](../../app/research.py)、[`app/library.py`](../../app/library.py)） |
| 原文溯源与防漂移定位 | 确定性代码 | 每条场地主张通过精确 `SHA-256` 绑定原件版本，仅在哈希一致且摘录在目标页唯一出现时才允许在 PDF.js 上绘制高亮；其余情况显式标为 `outside_scope`、`version_mismatch` 或 `missing_original`（[`app/site_facts.py`](../../app/site_facts.py)、[`web/reader.js`](../../web/reader.js)） |
| 先例段落提取 | 确定性规则 | 按 `Previous / Similar Application` 章节与附录表格切分，抽取编号、决定与日期；文句未载明决定时诚实标为 `unknown`（[`app/precedents.py`](../../app/precedents.py)） |
| 初步倾向判定 | 确定性规则 | 基于 `C1–C8` 固定规则对已采集字段与先例计数，不设加权黑盒分数（[`app/lean.py`](../../app/lean.py)） |
| 半结构化字段候选提取 | 模型（规划中） | 仅负责从用户指定的页面文本范围中提取候选字段与建议摘录，页码与坐标只作候选，最终位置由本地原文匹配确认（[`kimi-integration.md`](./kimi-integration.md)） |

## 2. 为什么设“阻断项”与“人工覆核闸”

在规划实务中，部分关键前提一旦缺失，后续所有正面因素都无法推导出可行结论。[`app/lean.py`](../../app/lean.py) 因此引入了两层硬约束：

- **阻断机制（Blocker）**：例如 `C4 許可狀態` 若存在未关闭的 `permission-status-eot` 待查事项（无法确认原许可是否已展开或已申请续期），`preliminary_lean()` 会直接返回 `證據不足`，不参与正负项抵消。
- **人工覆核闸（Provisional Gate）**：只要某条判断依赖的任何一条 `claim` 仍处于 `pending`（待覆核），或关联了未解决的 `issue`，该条判断自动标记 `provisional=True`（界面显示“暫定”）；规划署主文件挑选的 `C6 先例` 也强制标为暂定，并在界面横幅提示“非全区完整清单”。
- **边界声明**：系统明确不自动作最终专业判断（见 [`SPEC.md`](./SPEC.md) Non-goals），`初步傾向` 仅作为从业者覆核前的结构化草稿。

## 3. 云端 API 接入边界（Kimi Integration）

在 [`kimi-integration.md`](./kimi-integration.md) 中，第一版云端模型接入遵循“最小外发、本地留痕”原则：
1. **不默认上传整份原件或页面图像**：本地先完成 PDF 哈希校验与逐页文本提取（仅在原生文字不足时按页触发 OCR），向用户展示拟外发的页面文本范围后再请求 API；
2. **渠道与额度隔离**：区分个人交互式候选端点（Kimi Code）与产品集成端点（Kimi Platform），凭证仅存本机配置，不写入资料库、日志或归档；
3. **可回溯评测基线**：首案 `A/K1/265` 已固化官方文件快照与 21 项场地字段样板（[`app/sample_data/ak1_265.json`](../../app/sample_data/ak1_265.json)），后续接入模型提取时，将以从业者逐项覆核后的金标准对照评测字段准确率、引用定位成功率与角色混淆率（[`acceptance.md`](./acceptance.md)）。
