# 交互说明

沿用繁体中文、MiSans、中性视觉和现有资料库／专注阅读。新版三栏比例属于已有独立设计，不在本轮重做；新增覆核不能破坏文件切换、版本选择、历史范围及阅读位置恢复。

## 主要流程

1. 打开研究，显示按七类问题组织的场地资料表，主列为「項目」「數值或說明」「時間」「資料性質」「來源」「覆核狀態」。具体范围、阶段、陈述者、单位、约数／不等号、分母及方案关系可展开查看。
2. A/K1/265 样板建立时自动要求记录 as-of 日期并冻结文件哈希；发起提取前选择文件范围并检查存储。未缓存文件按需取得，显示处理范围及具体失败，取消保留已保存成果。
3. 每个字段可展开多个来源主张，按范围、阶段、方案与时间区分；疑似冲突并列，不自动选最大、最新或最完整值覆盖其它值。数字变化显示修订理由或“原因未知”，不自动解释成边界或实体变化。缺项列出具体缺口。
4. 点击来源打开正确版本和原文高亮；计算值展开公式及每个输入的证据。无法定位明确说明，不把人工备注伪装成原文。
5. 每项提供「確認」「修改」「移除」。修改可调整值、单位、时间、资料性质、范围、来源关联及备注；所有前后值保存。原文不改写，移除可恢复。
6. 用文字区分「待覆核」「已確認」「已修改」「已移除」。冲突、未知口径和缺资料另有状态；确认字段值不会消除未解决问题。
7. 保存失败明确显示未保存并允许重试。新分析独立展示，不覆盖人工字段或高亮；版本切换保留对应结果与阅读状态。

面板按需展开；窄窗口可在原文与列表间切换，返回保持位置。键盘可进入条目和操作，焦点可见。定位失败展示具体问题和原件入口，不在任意位置绘制高亮。

## 参考资料脉络

研究范围下展示四条证据链：OZP／Notes、规划申请与决定、BO 建筑记录、Lands 契约与批准。每项可查看来源版本、时点、适用理由、证据和覆核记录；「候選」「已確認適用」「已排除」「缺文件」「未研究」「不適用」「來源衝突」明确区分。各链覆盖度分别显示，不因取得规划决定便把 BO 或 Lands 标为完成。

允许人工加入有来源的参考及关联理由，以便覆盖尚无连接器的资料。确认适用与确认高亮是不同操作。人工确认只记录研究判断，不声称系统已作独立法律核定。

需要付费、业主授权或部门协助的文件进入「資料請求」清单，显示地址、PRN、lot／DD、文件、覆盖时点、预计费用、未决问题和状态。系统只协助准备和追踪请求；不会静默购买、使用私人账户或把一般政策页面当成个案文件。取得后由用户关联文件和实际来源。

当必填字段在原生文字中无法读取时，条目显示「需要 OCR」及影响页面；运行后显示 OCR 页数、工具配置与覆核状态。能从原生文字获得证据的页面不强制 OCR。

## 存储管理

显示受保护资料、可清理缓存及其它数据的实际占用，设置缓存上限。用户可查看保护原因和关联项目，主动保留原件；自动清理仅涉及可释放缓存。

空间不足时说明所需与可用空间（未知时不编造大小），提供清理缓存／项目归档入口。归档显示目标位置、内容和验证结果；验证成功后才提供释放本地副本选项。外置资料显示离线状态及重新定位入口。

恢复后保持高亮、历史和阅读状态，不以回到第一页作为恢复成功。普通 ZIP 原件导出继续保留；完整项目归档明确为独立操作，避免误把 PDF ZIP 当可恢复备份。

## 申请历史与待查事项

历史按事件展示申请、决定、有效期、撤销、续期和条件；保留原始日期含义。条件与部门意见分开，点击回到证据。问题列表关联具体字段、时间与版本，处理后显示解决理由及证据，原冲突记录仍可追溯。同一来源内出现不同日期时显示为来源内部冲突，不因来源官方而自动选一个。
