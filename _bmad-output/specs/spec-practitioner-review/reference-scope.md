# 适用资料范围与待研究问题

本文件规定产品研究范围，不提供 A/K1/265 的法律或规划适用性结论。最新官方来源追溯及样本证据见 adopted research companion；既有资料目录只作发现线索，不能单独当成现行可用性或个案适用性证据。

## 范围

| 证据链 | 首轮应记录和核实 | 个案仍可能缺少的材料 |
|---|---|---|
| OZP／Notes | 场地范围、图则编号与版本、研究 as-of 日期的状态、相关分区、规划意向、用途及限制条文；Notes 与确切图则版本配对，申请引用的历史版本另存 | 精确边界与跨分区对应、历史图则／Notes、修订关系、中英文条文核对 |
| 规划申请与决定 | 完整申请编号、提交及补充资料、部门意见、职员建议、会议决定、条件、有效期、撤销／失效；各角色和日期分开 | 未公开附件、来源内部日期矛盾、条件履行证据、后续关联申请 |
| BO 建筑记录 | 入伙纸、获批准一般建筑图则、改建／修订批准及相关编号；先从 BRAVO／BIC1／BIC3／BIC4 发现记录，再核实具体文件 | 网上无记录时的纸本查册、业主授权材料、图则的批准日期与覆盖范围 |
| Lands 契约与批准 | 先解析 PRN，再查现行及历史土地登记册、Government Lease／New Grant／Conditions、memorials；个案 waiver／STW 及附图独立取得 | IRIS 付费查册、业主或授权代表材料、DLO 提供的已签立文件、契约修订和覆盖地块 |

四条链均纳入证据记录和缺口管理；任何一条都不能替代另一条。不能从规划批准推导建筑或土地契约已获批准，不能以一般政策证明个案安排，也不能因网上未找到文件便判定文件不存在或无需考虑。

## 共同证据结构

每条保存：研究问题、明确场地／地段范围、研究时点、文件类别和版本、官方来源、获取时间、文件／生效时间（未知明确标记）、原文证据位置、关联理由、候选或覆核状态、覆核者及操作历史。一个参考可服务多个研究，但各自适用性判断独立。

保存检索范围、查过的来源及失败原因；缺文件、未研究、不适用和相互矛盾分别记录。来源是否官方、来源可靠度及是否获得独立佐证是不同字段；重复打开同一官方来源不算独立核实。确认适用须有人覆核证据；自动建议不是确认。

## 研究产出及进入实施的条件

对首案逐链建立来源清单和可复查路径；取得实际样本并记录哈希、日期、可取得限制和版本关系。识别未能取得的材料，建立 RecordRequest：地址、PRN、lot／DD、文件类别、覆盖时点、预计费用、未决问题、请求状态及取得后的来源。不能验证的接口不进入正式连接器范围。

A/K1/265 样板采用建立时明确记录的 as-of 日期；精确边界或个案文件不足转为 ResearchIssue，不再等待抽象时点决定。当前不自动启动付费查册、使用私人账户、外部上传或大规模搜集；用户取得受限文件后可继续关联和覆核。

## 与场地资料表的关系

OZP 与 Notes 的分区、规划意向、用途及限制条文按确切版本关联 SiteFact；申请文件转述的限制记录为该来源的主张，不能自动升级为现行上限。实际、申请、获批用途各自有依据，不能用其中一项推断另一项。

BO／Lands 缺资料或口径疑问转为 ResearchIssue，标明影响哪个参数或判断、所需资料以及已查范围。是否适用仍独立覆核；不同审批或契约范围不互相替代。只有来源定义或专业覆核支持时，建筑或土地文书中的面积／楼面术语才映射到场地资料表的 GFA、Site Area 或 PR 字段。
