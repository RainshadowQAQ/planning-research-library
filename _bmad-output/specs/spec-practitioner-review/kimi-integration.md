# Kimi API 接入边界

已决定以 Kimi 云端 API 支持第一版资料提取；Kimi Code 订阅端点仅作个人原型的优先核实候选。官方文档允许会员取得 API Key 并接入第三方开发工具，但其[使用规范](https://www.kimi.com/code/docs/en/kimi-code/community-guidelines.html)限定个人交互式使用，并将产品集成指向 Kimi Platform。用户主动点击不自动证明规划资料提取符合该订阅范围。正式接入前核实账户档位、凭证、适用条款与配额；如不适用，接 Kimi Platform，不改变本规格的证据和覆核模型。

默认数据流：本地 PDF 哈希校验及逐页文字／坐标提取 → 必要页 OCR → 用户选择研究问题和文件范围 → 展示拟发送的页面文字范围 → 经 Kimi API 返回字段候选 → 本地核对原文位置并保存输入范围、模型标识、配置、输出和人工覆核。原件、原始坐标、高亮与审计保留本地；整份 PDF 或页面图像不属默认外发内容。定位由本地原文匹配完成，模型生成的页码或坐标只作候选。

接入应提供可替换的 provider：凭证只存本机安全配置，不写入资料库、日志或归档；API 失败、额度不足、限流和中断保留既有成果，重试创建可追踪运行。请求在发出前检查实际字节／上下文限制，长文件按页或片段处理，不把订阅额度当无限批处理资源。Kimi Code 和 Kimi Platform 的 Key、端点及计费分别配置，不能混用。[Kimi Code 官方接入说明](https://www.kimi.com/code/docs/en/)；[错误与限额说明](https://www.kimi.com/code/docs/en/kimi-code/error-reference.html)。

接入核实项：本人账户能否取得 Kimi Code Key、调用权限和可用模型；规划文件分析是否符合订阅用途；实际请求大小、速率与配额；敏感页面是否允许发送。核实结果写入运行配置后，才把某个渠道列为可用。样板资料表制作不依赖 API 调用。
