# 场地资料字段与证据要求

本表为核心成果的数据契约。用户七类问题是本轮输入依据；不是 A/K1/265 已核实结果。不得将参考 DOCX 中的其它案例数字填入首案。研究已证明同一参数会因范围、阶段、日期或修订而有多个合法值，因此每个值先视为来源主张，不能先压成唯一“场地真值”。

## 七类研究问题

| 研究问题 | 字段与要求 |
|---|---|
| 这是什么场地 | 地址、地段编号、研究边界、Site Area、是否包含政府土地；能取得时另记政府土地面积。位置点、地段边界、申请边界与楼层范围分别表达 |
| 土地和建筑目前是什么用途 | 实际用途、申请用途、获批用途、OZP 分区分别记录；未核实实际用途不能由分区或批准用途推定 |
| 发展规模是多少 | Site Area、GFA、PR、Site Coverage、BH、层数及用途相关容量，例如房间、床位、单位、座数、车位；容量字段按实际用途选择 |
| 参数代表什么 | 现状、申请方案、批准内容、规划上限分开；标明原文报告、单位换算或自行计算，不能将不同阶段合为唯一数值 |
| 适用什么规划资料 | 对应版本的 OZP、Notes、规划意向、相关用途、限制条文；每个关联有研究时点、出处和适用性覆核 |
| 有什么申请历史和条件 | 历次完整申请编号、决定、有效期、撤销、续期、批准条件、相关部门意见；保留具体事件和条件来源 |
| 有什么无法确定 | 数字冲突、未知面积或计算口径、缺失文件、BO／Lands 待查事项；状态及解决依据可追踪 |

## 每项资料记录

一项字段可有多个有独立出处的主张。保存稳定 ID、字段名、原始文字／数值、原始单位、可选规范化值、具体研究范围、申请／方案／事件关联、时间、资料性质、来源和覆核状态，并包含：

- `scope_kind`：整幅地段、申请范围、发展范围、建筑物、楼层、政府土地部分或未知。
- `source_stage`：申请文件、补充资料、部门意见、职员建议、会议决定、撤销／失效、OZP／Notes、意向／招标、建筑记录、土地文书或未知。
- `asserted_by`：申请人、规划署、城规会、其它部门、地政总署、屋宇署、业主／顾问或未知；它说明谁作出主张，不等同来源发布者。
- `approximation`：精确、约数、上限、下限、范围或未知；原文的约数、不等号和限定词保留。
- `denominator`：PR、百分比或密度计算所用面积及其字段版本；不明确时保持未知。
- `supersedes`：本主张明确修订或取代的较早主张；正常并存值不强设关系。
- `conflict_reason`：同范围同阶段同时间仍不一致、日期矛盾、口径不明、修订原因已知或未知。

- 时间：研究时点、文件日期、事件日期、有效起止及获取时间按已知含义分别记录；不适用或未知有明确原因，不能编造时间。所谓“目前”要有核实截至日期。
- 资料性质：现状／申请方案／批准内容／规划上限／招商或意向参数／未知。另设生成方式：原文提取／换算／计算／人工补充；计算方式不抹去所属方案阶段。
- 来源：文件身份、具体版本哈希、页码／区域或可验证的原文定位、摘录和来源链接；多来源逐个保留。非 PDF 不伪造页码，保留实际定位方式；具体格式支持范围另行选型。
- 覆核：待覆核／已确认／已修改／已移除，包含事件历史、时间、前后值及覆核者。缺口和冲突状态独立于覆核状态。
- 人工修正不改写机器原始候选。人工输入而无证据时明确标记，不能展示为官方已证实。字段值确认不自动确认参考文件适用性。

## 数值及范围

Site Area 保留来源所指的地段、申请、实际使用或其它范围，含政府土地与否不明时标为未知。GFA 保留总量与住宅／非住宅等拆分，以及原文计入范围；不混同其它楼面面积指标。

PR 保留原文值和分母。若自行计算，保存公式、输入字段版本、单位、面积口径及舍入规则；分母未知或范围不一致时不计算，不以比值替代原文或规划上限。约数 Site Area 乘 PR 只能产生明确标记的估算值，不能变成精确法定 GFA。“总楼面面积”只有来源定义或专业覆核支持时才映射为 GFA。Site Coverage 保留百分比及来源范围；BH 保留 m、mPD 等单位和高度基准，层数独立，基准未知时不可强行比较。

不同文件／日期／方案的值并列。只有确认同一范围、阶段、时间和口径后才能判断数值冲突；正常版本变化不自动视为错误，也不能仅因数字增大便认定场地扩张。修订应保留原值、修订值、来源及已知理由。没有提取到、缺少文件、尚未研究、不适用、来源冲突、未知和数值为零分别表示。

## 已验证的抽取陷阱

研究样本显示，申请范围、发展范围、私人土地和政府土地可能在同一文件中各有面积；PR 的分母可能只采用其中一种。补充资料也可能只是修正漏计容量而没有改变边界、布局或高度。批准和后来撤销必须保存为不同事件；表头之外的脚注可能决定混合分区、政府土地或统计范围。意向征集及拟议卖地参数属于提案阶段，不能当成已批准发展；区域层面的分区资料不能证明具体门牌或地块参数。

系统据此执行五条规则：先读取表体和脚注；先比较范围和阶段再比较数字；保留更正原因；不把圆整数字推导成精确上限；不能由邻近或区域资料填补精确场地证据。

## 历史与条件

一项申请可有多个事件。续期、新申请和明确关联申请不并成同一记录；批准与后来撤销均保留。条件保留内容、来源、所属决定、期限及起算依据；期限依据未知不生成虚假截止日。部门意见不等于最终批准条件，条件未取得履行证据时不标已履行。

## 需求依据

本轮直接依据用户提供的七类问题。前轮五份 DOCX 为需求示例，说明参数表、案例历史和比较方式；本规格不把其中其它项目数字填入 A/K1/265、不修改原文件，也不把招商说明当作官方批准证据。详细个案证据和官方来源见 adopted research companion；产品范围见 reference-scope.md。同一官方来源由不同步骤重新打开只算一次来源，来源可靠度与独立佐证分别记录。
